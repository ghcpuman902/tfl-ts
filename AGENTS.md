# AGENTS.md

See [CLAUDE.md](./CLAUDE.md) — tfl-ts's agent quick-start doc. It applies to any coding agent (Claude, Cursor, Codex, Copilot, and others), not just Claude specifically.

No repo access? Read it offline once the package is installed:

```bash
npx tfl-ts docs cat CLAUDE.md
```

See also `npx tfl-ts docs ls` for every bundled agent-facing document, and [docs/design/agent-friendly-cli.md](docs/design/agent-friendly-cli.md) for why this file and the `tfl docs` command exist.
