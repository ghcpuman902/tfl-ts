## Construct-time (runtime)

## Risks considered and still accepted

- **Main entry is not the client-bundle win.** `import TflClient` still statically imports every wrapper module. Shipped because `/ui` and `/meta` are what a browser should import.
- **Dual-package hazard.** CJS and ESM copies can duplicate in a mixed graph. A minor cannot drop CJS. `exports` maps `import` to ESM and `require` to CJS.
- **`sideEffects: false`.** Safe after `src/index.ts` is re-exports only. Enforced by the `/ui` fixture asserting no sequences / raw / `TFL_APP_KEY`.
- **`createRequire` getter.** Some bundlers may still treat the getter as a static dependency. Documented topology path is `tfl-ts/meta`. The getter is compatibility for `client.line.STATION_SEQUENCES`.
- **Getter enumerability.** `Object.keys(client)` does not list `line` until that getter runs. Call sites use property access.
- **Deep imports of `tfl-ts/dist/...`.** Emit is now `dist/cjs/` and `dist/esm/`. Public API is `exports`. Types that used `tfl-ts/dist/generated/types` should use `tfl-ts/dist/cjs/generated/types` or `tfl-ts/dist/esm/generated/types`.
- **Lazy `raw` still parses every tag file** when `RawClient` is imported. Allocation of `travelTime` waits until first access. Not an 84-endpoint tree-shake.
